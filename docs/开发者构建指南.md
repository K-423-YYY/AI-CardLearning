# 开发者构建指南

## 本地运行

```bash
python serve.py
```

访问 `http://127.0.0.1:8765`。

`serve.py` 使用自定义 MIME 映射，保证 `pdf.mjs` 与 `manifest.webmanifest` 正确加载；不要直接用 `python -m http.server` 代替。

## 测试

```bash
npm test
```

浏览器端到端测试需要本机 Chrome，并先启动本地服务器：

```bash
python serve.py
node tests/e2e-smoke.js
node tests/e2e-verify.js
```

当前单元测试共 27 项，覆盖学习区、每日队列、答题判定、错题、复习排期、关卡排版、批量操作、导入导出、设置加密、本地 AI 文件筛选/批量生成、Word 解析、双库成对卡片、收藏/搜索/删除、记忆卡学习与四阶段精炼。

## PWA

`app/manifest.webmanifest` 提供安装元数据，`app/sw.js` 负责静态资源缓存。部署时把 `app/` 放到任意 HTTPS（或 localhost）静态服务器即可。

## Windows 桌面版（Electron）

```bash
cd desktop
Copy-Item -Path ../app -Destination app -Recurse -Force
npm install
npm start
npm run dist
```

产物在 `desktop/dist/`，Release 中对应 `AI.Setup.0.2.0.exe`（安装版）和 `AI.0.2.0.exe`（免安装版）。主进程通过 preload 暴露 `window.desktopAPI`，导出/导入备份会使用系统原生文件对话框。

> 说明：v0.2.0 默认使用 IndexedDB 作为本地存储，数据位于 Electron 用户数据目录；应用不包含开机自启项，卸载时会结束运行中的进程。

## Android APK（Capacitor）

```bash
cd android
npm init -y
npm install @capacitor/core@8 @capacitor/cli@8 @capacitor/android@8 @capacitor/filesystem@8
npm install ./local-plugins/ailearn-directory-picker
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

生成 APK 后，正式发布前：

- 将 `AndroidManifest.xml` 的 `android:allowBackup` 改为 `false`
- 使用自有签名或调试签名

前置环境：Node.js 22+ 与 Java 17+（推荐 Java 21）。CI 已固定使用 Capacitor 8。

Android APK 在 Release 中对应 `app-debug.apk`；覆盖安装新版不会清除本地数据，卸载才清空。

## GitHub Actions

仓库根目录 `.github/workflows/build.yml` 已配置 Windows 与 Android 两条构建流水线：

- 推送 `v*` tag 或手动触发时执行
- Windows：构建 NSIS + portable
- Android：安装 Capacitor、生成 Android 工程并 `assembleDebug`
- 构建产物上传为 workflow artifacts；推送 `v*` tag 时自动发布 Release 并附带安装包

## 版本与缓存

- 当前版本：`0.2.0`
- 应用资源版本：`v32`
- Service Worker 缓存名：`ai-learn-local-v16`，升级会自动清理旧缓存
- 应用启动时自动检查 GitHub 最新 Release，发现新版本会提示下载

# 数据格式说明

## 导出文件

导出统一为单个 `.zip`，文件名示例：

```text
AI闯关学习备份-2026-08-01.zip
```

内部结构：

```text
manifest.json
data.json
files/
  file_1.txt
  file_2.pdf
```

## manifest.json

```json
{
  "format_version": 2,
  "app_version": "0.2.0",
  "exported_at": "2026-08-01T12:00:00+08:00",
  "export_type": "full",
  "source_app": "ai-learn-local"
}
```

`export_type` 可选：

- `full`：全量备份，包含所有学习区、卡片、进度、复习计划和非敏感设置
- `zone`：单个学习区分享

## data.json

结构化数据包含：

- `profile`：昵称、每日卡片数
- `zones`：学习区
- `files`：文件元数据（正文放在 `files/` 中）
- `cards`：闯关卡（题干、选项、答案、解析、收藏、出处、路径、记忆卡关联）
- `memory_cards`：记忆卡（正面标题、背面内容、学习提示、出处、路径、收藏）
- `records`：答题记录
- `zone_settings`：学习区设置（每日卡片数、排序模式、关卡学习模式）
- `levels`：关卡
- `level_cards`：关卡与卡片映射
- `review_schedule`：复习排期
- `daily_tasks`：每日任务
- `checkins`：打卡记录

## 导入规则

- 导入前校验 `format_version`，不兼容时拒绝导入
- 全量备份支持“整包导入”或“选择学习区导入”
- 同名学习区提供三种处理：覆盖、保留两份、跳过
- 导入时可选择“保留原进度”或“重新闯关”
- 导入完成后立即生效，全程离线

文件记录支持 `kind`（`text` / `image`）和 `mime_type` 字段，用于区分普通文本与图片附件；旧备份导入时会自动按文本处理。

AI 分析返回的知识点可能包含试卷字段：`exam_type`、`exam_question`、`exam_options`、`exam_answer`，用于原样保留客观题并支持生成卡片时打乱选项。

闯关卡与记忆卡通过 `pair_card_id` / `memory_card_id` 一一对应；两张卡共享难度、结构路径与生成顺序，因此两个卡片库中同一知识点的位置保持一致。`favorite` 为 1 的卡片会置顶并出现在收藏库。

## API Key 安全

- API Key 仅保存在本机，导出文件不包含 API Key 与服务商密钥
- 备份文件可以放心发给他人

## 当前版本

- 当前应用版本：`0.2.0`
- 导出格式版本：`format_version = 2`
- 兼容导入：`format_version = 1` 的旧备份仍可导入，旧备份中的卡片按闯关卡处理，记忆卡库为空

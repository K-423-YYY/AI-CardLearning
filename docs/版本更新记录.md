# 版本更新记录

## v0.2.0 · 第四批

发布日期：2026-08-05

- 🗂️ 新增关卡项目管理：学习区支持多个关卡项目，每项目独立展示 Duolingo 路径
- 🏷️ 关卡项目左侧标签栏显示，点击切换，每项显示通关进度（已通关/总数）
- ➕ 支持新建关卡项目，可自定义项目名称
- 🔧 修改排序或每日卡片数保存时提示"覆盖当前项目"或"新建项目"
- ☁️ 新增"云盘同步"页面（设置页入口），支持 WebDAV 协议
- ☁️ 预置7个主流云盘 WebDAV 地址模板（坚果云/TeraCloud/InfiniCLOUD/Box/NextCloud/群晖/自定义）
- ☁️ 云同步支持测试连接、手动上传/下载/双向同步、自动定时同步
- 💬 新增"对话式 AI 分析"模式（AI 分析页入口），四阶段独立对话+微调重新生成
- 🔧 修复多项底层 bug（弃用 API、打卡无限循环、写操作竞态、双写、去重静默跳过等）
- 🚀 IndexedDB 版本升级至 v4，新增9个索引加速查询，新增TTL内存缓存
- 🚀 GET请求读写锁分离，提升并发性能
- 🧪 27项单元测试全部通过，零回归

## v0.2.0

发布日期：2026-08-03

- 新增记忆卡：每个知识点同时生成闯关卡和记忆卡，两张卡一一对应并保持相同位置
- 卡片列表升级为三个库：闯关卡库、记忆卡库、收藏库，均支持搜索、收藏置顶和三横杠菜单
- 三横杠菜单支持按难度/知识块排序、勾选删除（可联动删除对应卡）和选择学习
- 记忆卡使用翻面学习方式，自评“认识/不认识”，错误进入错题与复习流程
- 学习区新增“闯关卡 / 记忆卡”关卡模式切换，排序、错题和间隔复习规则保持一致
- AI 趋势分析新增可选“四阶段精炼”：结构范围分析（含疑似错误清单）、延伸补充、结构化拆解、成对卡片生成
- 导出格式升级为 `format_version = 2`，包含记忆卡、收藏、路径和关卡学习模式；旧 v1 备份仍可导入
- 更新 README、用户使用说明、数据格式说明和版本更新记录
- 修复旧版本升级后 IndexedDB 缺少 `memory_cards` 存储导致进入学习区失败的问题：数据库版本升级为 2，自动补齐缺失存储并保留原有数据；同时清理旧 Service Worker 缓存

## v0.2.0 · 第二批

发布日期：2026-08-03

- 学习区支持置顶与删除：手机端右滑显示操作，桌面端右键显示操作，首页新增置顶学习区
- 收藏库新增闯关卡区与知识卡区双分区，同一界面并列显示
- 收藏和位置联动：收藏一张卡时对应卡同步收藏，拖动排序时另一张对应卡跟随
- 闯关卡库、记忆卡库、收藏库支持手动拖动排序
- AI 分析与四阶段精炼结果保存最近 10 次，可查看记录、直接使用或回档
- 四阶段精炼每个阶段支持单独重新生成
- 首页与学习区新增日历窗口，完成关卡自动打勾，未完成打叉
- 修改每日卡片数或排序方式时，可选择新建后续关卡或覆盖原有关卡
- 全局 UI 应用天空配色与飞书简洁中性按钮风格

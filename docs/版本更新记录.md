# 版本更新记录

## v0.1.4

发布日期：2026-08-01

- 本地优先的 AI 闯关学习应用发布
- 支持学习区、文件上传、AI 生成卡片、每日闯关、错题集、间隔复习
- 支持本地备份导出与导入
- 支持 DeepSeek / OpenAI / Kimi / 通义 / 智谱 / 硅基流动等 OpenAI 兼容接口

## v0.1.5 · 第一批

发布日期：2026-08-01

- 修复 Toast 提示不会自动消失的问题，统一 3 秒自动消失
- 上传成功后提示是否立即进行 AI 分析
- AI 分析页支持选择要分析的具体文件
- AI 分析按文件/分块并行，卡片生成支持并发与批量生成
- 新增本地 AI 文件筛选与批量生成测试

## v0.1.5 · 第二批

发布日期：2026-08-02

- 电脑和手机可分别设置备份目录
- 导入备份时优先打开已设置的备份目录
- 移除单次上传 5MB 限制
- 支持 Word(.docx) 文本解析
- 支持图片上传与视觉 AI 分析
- 新增文档解析测试并更新全部说明文档
- 清理旧 Service Worker 缓存

## v0.1.5 · 第三批

发布日期：2026-08-02

- AI 分析和卡片生成新增四档加速：普通 / 5倍 / 10倍 / 20倍
- 档位起始文件大小可由用户自定义
- 新增试卷识别：选择题和判断题原样保留题干与选项
- 生成试卷卡片时自动打乱选项顺序
- 安卓端导出备份改为原生目录选择器，支持本地文件夹和网盘/云盘目录
- 重新构建并替换 v0.1.5 Release 安装包

## v0.1.5 · 第四批

发布日期：2026-08-02

- 修复关卡完成后“返回路径”未刷新进度的问题
- 完成当前关卡后标记为“已通关”，下一关自动解锁为可学习状态
- 新增关卡完成回归测试
- 新增版本更新记录文档

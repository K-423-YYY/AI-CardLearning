# 用户使用说明

## 打开应用

- 浏览器版：运行 `python serve.py` 后访问 `http://127.0.0.1:8765`
- PWA：在 Chrome/Edge 地址栏点击“安装应用”，之后可像原生应用一样打开，断网也能继续用
- Windows 桌面版：安装 `desktop/dist/` 生成的安装包即可
- Android：安装 `android/android/app/build/outputs/apk/debug/app-debug.apk`

应用打开后直接进入首页，不需要注册和登录。

## 新建学习区

1. 首页点击“+ 新建”
2. 输入名称，也可以留空使用默认名称
3. 创建后进入学习区详情

## 上传资料

支持：

- `txt`
- `md`
- `cpp`
- `h`
- `py`
- `pdf`（需要可复制文字的 PDF，扫描图片无法提取）
- `docx`（Word 2007 及以上）
- 图片：`png`、`jpg/jpeg`、`gif`、`webp`、`bmp`

上传大小不受应用限制，实际受设备和存储空间影响。上传成功后应用会询问是否立即进行 AI 分析；选择“立即分析”后，可以在 AI 分析页勾选本次要分析的文件。

## AI 生成卡片

1. 点击“AI 趋势分析”
2. 勾选要分析的文件（刚上传时默认勾选新文件，普通进入时默认全选）
3. 应用会把选中的文件发给 AI，整理成知识区块和知识点清单
4. 确认知识点后点击“确认生成卡片”
5. 每一条知识点生成一张四选一知识卡片

分析会显示实时进度；应用会根据文件大小自动选择“普通 / 5倍 / 10倍 / 20倍”加速档位，并显示“进度 X/Y（百分比）”。档位起始大小可在“设置 → AI 加速档位”中修改。

AI 分析页会显示推荐档位、文件大小、分析任务数和生成批次；分析或生成过程中可以手动切换档位，剩余任务会立即按新档位执行。20倍档采用 20 路并发、每批 10 张，避免单次输出过大。

图片分析需要使用支持视觉能力的 AI 模型；如果当前模型不支持图片，应用会提示更换模型。

如果上传的是试卷，AI 会识别选择题和判断题，原样保留题干与选项；生成卡片时自动打乱选项顺序。计算大题、主观题和普通资料仍按原流程处理。

首次使用需要先在“设置”里配置 AI 服务商：

1. 打开设置 → AI 服务商
2. 选择一个模板（DeepSeek、OpenAI 等）
3. 填入接口地址和接口密钥（API Key）
4. 点击“获取模型”，选择一个模型
5. 点击“保存配置”和“启动此服务商”

没有 API Key 时无法生成新卡片，可以先导入 `samples/示例学习区.zip` 体验完整流程。

## 卡片库

学习区详情页的卡片列表改为三个库：

- 闯关卡库：存放四选一闯关卡片，每张卡都有题干、选项、答案和解析
- 记忆卡库：存放与闯关卡一一对应的记忆卡，正面是知识标题，背面是详细内容、学习提示、出处和结构路径
- 收藏库：查看所有已收藏的闯关卡和记忆卡

每个库顶部都有搜索框，可按关键词筛选标题、题干、背面内容、出处或路径。点击卡片右上角的星号可以收藏，收藏后卡片会置顶并出现在收藏库。

每个库右上角的三横杠菜单提供：

- 筛选模式：按难易程度排序，或按知识块结构排序
- 删除卡片：勾选后批量删除，删除前会弹窗确认，可勾选“同时删除对应的另一张卡”
- 选择学习：勾选若干卡片开始学习，闯关卡沿用四选一答题，记忆卡使用翻面记忆方式

## 四阶段精炼

在“AI 趋势分析”页可以选择“四阶段精炼”生成方式：

1. 结构范围分析：AI 输出领域范围、章节大纲和疑似错误清单，逐条“采纳/忽略”后确认
2. 知识延伸与补充：AI 生成关联高阶概念、应用案例、易混淆辨析等扩展内容，可逐条取舍或整块跳过
3. 结构化拆解：AI 把知识点拆成原子条目并构建 大结构 → 结构 → 区块 知识树，选择“由易到难”或“按结构”排序
4. 生成卡片：每个原子条目生成一张闯关卡和一张记忆卡，写入对应的卡片库

“快速生成”仍然保留为默认方式。

## 关卡学习模式

学习区详情页可切换关卡学习模式：

- 闯关卡模式：关卡内使用四选一答题，答对/答错判定与原有流程一致
- 记忆卡模式：关卡内使用记忆卡翻面学习，点击“显示背面”后自评“认识/不认识”，不认识会进入错题与复习流程

两种模式的关卡数量、排序、每日卡片数、错题重排和间隔复习规则完全相同，各自记录学习进度。

## 每日闯关

- 每天任务 = 新卡片 N 张（默认 5 张，可在设置或学习区内修改） + 之前正确卡片的间隔复习 + 之前错误卡片的强化复习
- 点击闯关路径上的节点开始答题
- 答对：显示解析，卡片移出队列
- 答错：显示正确答案和解析，卡片回到队尾，下次出现时重新打乱选项
- 同一卡片当天连续答错 3 次：标记为“重点复习”
- 正确卡片按 1、2、4、7、15 天间隔复习，多次稳定后会加入 30 天间隔
- 错误卡片优先进入新学关复习队列，答对后从短间隔重新建立记忆
- 全部答完才算今日通关，并自动打卡

## 错题集

- 答错的卡片会自动收进“错题集”
- “单独复习”：只练习错题，不影响今日任务
- “加入今日练习”：把错题追加到今天的学习队列

## 复习机制

- 新学关卡里会交错出现新卡片、正确卡片复习和错题强化复习
- 正确卡片：采用间隔重复，按 1、2、4、7、15、30 天安排
- 错误卡片：当前关卡内重做、次日优先安排，答对后重新建立复习周期
- 答题时页面会显示“新学 / 间隔复习 / 错题强化”标识

## 设置

- 昵称：本地显示名称
- 每日学习卡片数：1-100
- AI 服务商：模板、接口地址、接口密钥（API Key）、模型
- 本地备份：导出压缩包、导入压缩包

## 备份与恢复

导出：

1. 打开“设置”
2. 点击“导出完整备份（压缩包）”
3. 导出前可先在“备份目录”中指定保存位置；未设置时使用系统默认位置
4. 导出完成后会显示保存位置，并可打开对应文件夹

导入：

1. 打开“设置”
2. 如果设置了备份目录，应用会优先打开该目录
3. 选择压缩包文件后，同名学习区可选择“覆盖 / 保留两份 / 跳过”
4. 可勾选“保留原学习进度”，取消勾选则重新闯关

备份中不会包含 API Key。

## 数据删除

- 删除学习区：目前请通过导入覆盖或备份后重建；删除卡片可在“知识卡片”页面操作
- 卸载 PWA/桌面应用会清空本机数据
- 浏览器清除站点数据也会清空数据，所以请定期导出备份

## 更新到新版本

1. 应用启动时会自动检查 GitHub 最新版本，发现新版本会弹窗提示
2. 点击“前往下载”，或直接打开 GitHub Releases 页面
3. Windows 下载 `AI.Setup.0.2.0.exe`，Android 下载 `app-debug.apk`
4. 直接安装新版覆盖旧版，学习数据会自动保留；不要先卸载旧版

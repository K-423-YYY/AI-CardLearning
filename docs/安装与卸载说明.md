# 安装与卸载说明

## Windows 电脑版

1. 打开项目 GitHub Releases 页面
2. 下载 `AI闯关学习-Setup-x.x.x.exe`（安装版）或 `AI闯关学习-x.x.x-portable.zip`（便携版）
3. 安装版双击运行，按提示安装；便携版解压后双击 exe 即可
4. 打开后直接进入首页，不需要注册、登录、服务器或额外配置

卸载：

- 安装版：在“设置 → 应用”中卸载
- 便携版：删除解压目录即可
- 应用不添加开机自启项，也不常驻后台；卸载器会先结束正在运行的进程，卸载后不会残留启动项
- 数据只保存在本机；卸载前如需保留数据，请先在“设置”中导出备份

## Android 手机版

1. 打开项目 GitHub Releases 页面
2. 下载 `app-debug.apk`（或正式签名 APK）
3. 手机允许“安装未知来源应用”后安装
4. 打开即用，不需要账号或服务器

卸载：

- 在系统设置中卸载应用
- 卸载即清空本机数据（已配置 `allowBackup=false`），不会残留后台进程或启动项

## 数据说明

- 所有学习区、卡片、进度、复习计划都保存在设备本地
- API Key 只保存在本机，不会写入导出备份
- 建议定期在“设置”中导出 `.zip` 备份，可存网盘或云盘
